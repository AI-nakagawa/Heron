# 現場面積ノート（v11）

三角形（ヘロンの公式）と台形を辺で接続し、連続図面として計算・端末内保存できるスマートフォン向けPWAです。台形は中央・左・右揃えに対応し、図面と計算表は「PDF出力」から端末の印刷機能を使ってPDF保存できます。

## 音声入力（まとめ入力）

「まとめ入力」欄の🎙を押すとキーボードが開くので、キーボードのマイクを押して寸法を続けて話します。

- 三角形の最初の1つ: 「3.01、4.25、3」→ a・b・c
- 2つ目以降（c は接続辺で自動）: 「4.25、3.01」→ a・b
- 台形: 上底・下底・高さ（2つ目以降は上底・高さ）
- 「3点01」「三点〇一」「3メートル1センチ」「4m25」なども数値に直します。読み取った値は欄の下に表示されます
- 数がそろったら、キーボードの完了（改行）キーで図形を追加できます

Webアプリからキーボードの音声入力を自動開始することはできないため、最後のマイクのタップは手で行います。音声入力のオフライン可否は、スマホ本体のキーボード・言語パック・設定に依存します。個別の寸法欄にも「3点01」のような文字が入った場合は数値に直します。

## v11 で追加した機能

- **設計面積との比較**: 設計面積を入れると、合計の下に差（m²）と比率（%）を表示。保存・CSV・PDFにも出力
- **追加前のプレビュー**: 寸法を入れると、図面に追加位置を点線で表示し、その図形の面積と追加後の合計を表示
- **a と b の入れ替え**: b は接続辺の始点側、a は終点側に付きます。点線の図形で向きを確認し、逆なら「⇄ a と b を入れ替え」
- **途中の図形の修正**: 「追加した図形」の各行の「修正」から寸法を直せます。後ろにつながる図形も作り直し、成り立たなくなる場合は修正できません
- **細長い三角形の警告**: 最小角が20°未満の三角形は、テープの誤差が面積に大きく響くため警告
- **重なりの警告**: 既存の図形と重なる場合は警告し、追加前に確認（「接続方向を反転する」の付け忘れ対策）
- **頂点名**: 図面・接続辺の一覧・PDFに A, B, C… を表示
- **設定**（右上）: 面積の桁数（小数第1〜3位）・丸め方（四捨五入／切り捨て／切り上げ）・合計の出し方（合計してから丸める／図形ごとに丸めて合計）
- **屋外モード**（右上「☀ 屋外」）: 高コントラスト・大きいボタン
- **画面の消灯防止**: 使用中は画面を消灯させない（対応ブラウザのみ。設定で切り替え）

v10 以前に保存した図面もそのまま開けます（接続関係は点の位置から復元します）。

## GitHub Pagesで公開する

1. このフォルダー内のファイルをGitHubリポジトリのルートへ置きます。
2. GitHubの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、対象ブランチのルートを公開します。
4. 発行されたHTTPSのURLをスマートフォンで開き、ブラウザの「ホーム画面に追加」を選びます。

更新後、ホーム画面のアプリに反映されないときは、アプリを一度閉じて開き直してください。

## データについて

記録はブラウザの端末内ストレージに保存され、アプリ独自のサーバーには送信しません。音声入力の処理方法と通信の有無は、iPhoneまたはAndroidのキーボード設定に依存します。必要な図面は当日中にPDF・CSV・JSONで出力してください。

## 構成

- `index.html` — 画面
- `styles.css` — スマートフォン向けデザイン
- `mobile-input.css` — 下部ボタン配置
- `features.css` — v11 の追加機能（まとめ入力・プレビュー・設定・屋外モード）
- `numbers.js` — 音声入力の文字列から数値を取り出す
- `app.js` — 計算、図面、履歴、出力・復元
- `manifest.webmanifest` — PWA設定
- `service-worker.js` — オフラインキャッシュ
- `icons/icon.svg` — アプリアイコン

PWA機能はHTTPSまたはlocalhostで動作します。ファイルを直接開いた場合、計算と保存は使えますが、インストールとオフラインキャッシュは有効になりません。
