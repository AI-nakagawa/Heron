# 現場面積ノート

三角形（ヘロンの公式）と台形を辺で接続し、連続図面として計算・端末内保存できるスマートフォン向けPWAです。台形は中央・左・右揃えに対応し、図面と計算表は「PDF出力」から端末の印刷機能を使ってPDF保存できます。

対応ブラウザでは、名称・寸法・現場メモのマイクボタンから日本語の端末内音声入力を利用できます。初回のみ、通信できる場所で「オフライン音声を準備」を押して日本語音声パックをダウンロードしてください。準備完了後は音声を外部へ送らず、オフラインで認識します。寸法は認識された内容と数値を確認・修正してから入力欄へ反映します。「12点35」「12.35メートル」「12メートル35センチ」などに対応します。

端末内音声認識は新しいブラウザの実験的機能です。アプリが端末上で日本語音声パックの提供状況を確認し、非対応の場合は「利用できません」と表示します。オンライン音声認識へ自動的に切り替えることはありません。

## GitHub Pagesで公開する

1. このフォルダー内のファイルをGitHubリポジトリのルートへ置きます。
2. GitHubの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、対象ブランチのルートを公開します。
4. 発行されたHTTPSのURLをスマートフォンで開き、ブラウザの「ホーム画面に追加」を選びます。

## データについて

記録はブラウザの端末内ストレージに保存され、アプリ独自のサーバーには送信しません。音声入力は `processLocally` を強制し、認識時に音声を外部サービスへ送らない方式です。初回の日本語音声パック取得には通信が必要です。ブラウザのデータ消去・機種変更に備え、履歴画面から定期的にJSONバックアップを保存してください。CSVはExcel等での集計用です。

## 構成

- `index.html` — 画面
- `styles.css` — スマートフォン向けデザイン
- `offline.css` — オフライン音声入力の状態表示
- `app.js` — 計算、履歴、合計、出力・復元
- `manifest.webmanifest` — PWA設定
- `service-worker.js` — オフラインキャッシュ
- `icons/icon.svg` — アプリアイコン

PWA機能はHTTPSまたはlocalhostで動作します。ファイルを直接開いた場合、計算と保存は使えますが、インストールとオフラインキャッシュは有効になりません。
