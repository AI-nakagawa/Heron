# 現場面積ノート（v12）

三角形（ヘロンの公式）と台形を辺で接続し、連続図面として計算・端末内保存できるスマートフォン向けPWAです。台形は中央・左・右揃えに対応し、図面と計算表は「PDF出力」から端末の印刷機能を使ってPDF保存できます。

## 図面を見ながら入力（v12）

「📐 図面を見ながら入力」（図面右上の「📐 入力」でも可）を押すと全画面になり、キーボードを出したままでも、上に図面、下に入力欄と「追加」が並びます。スクロールせずに次の流れを繰り返せます。

1. キーボードのマイクで寸法を続けて話す（例「4.25、3.01」）
2. 図面の点線で追加位置を確認（向きが逆なら上の「⇄ a・b」、内外が逆なら「反転」）
3. 改行キーか「追加」で追加 → 入力欄は空になり、キーボードは出たまま。次の寸法を話す

- 接続する辺は、全画面の図面で緑色の辺をタップして選びます。追加した直後は、新しい図形の辺が自動で選ばれます
- 上のボタン: ✕（閉じる）・△三角形／▱台形の切り替え・⇄ a・b・反転・↶ 戻す
- 「123」で数字キーボードに切り替え（手入力向け）。数字キーボードには区切りのキーが無いので「次␣」で区切ります。「🎙あ」で音声入力できるキーボードに戻ります（選んだ方を覚えます）
- Android の戻るボタンでも全画面を閉じます

## 「はい」「OK」で図形を追加（v12.3）

数がそろった後に「はい」「OK」と言うと、その時点で図形を追加します。手で「追加」を押す必要はありません。

- 2つ目以降の三角形: 「4.25 はい 3.01 はい」→ 2つ目の「はい」で追加。「4.25 OK 3.01 OK」でも同じ
- 最初の三角形は3つ必要なので、「3.01 はい 4.25 はい 3 はい」の3つ目の「はい」で追加
- 合図は「はい」「ハイ」「はーい」「OK」「オッケー」「オーケー」のどれでも可。混ぜても構いません
- 数がそろう前の合図（1つ目の数字の後の「はい」など）は、次の数字を待つだけです
- 追加すると入力欄はそのまま次の寸法を待ちます。Android では短く振動します。続けて話せば次の図形も同じように追加できます
- 寸法が成り立たない（三角形にならない）ときは追加せず、「追加できません…読み直してください」と出ます。そのまま次の寸法を話せば、そこから読み直します
- 既存の図形と重なるときは、追加する前に確認画面が出ます
- 入力欄には話した文字がそのまま残ります（音声入力中に書き換えると、iPhone で文字が二重になることがあるため）。入力欄から離れたときに、使い終わった部分を消します
- 右上の「設定」でオフにすると、合図では追加しなくなります（改行キーか「追加」で追加）
- v12.4: 1つの面のはずが2枚・4枚と増える不具合を修正。追加のときにカーソルを動かさないようにした（音声入力中に動かすと、話した文字がもう一度入ることがあるため）。それでも同じ言葉がそっくり二重に入ったときは、読み飛ばして「同じ言葉が二重に入ったため、読み飛ばしました」と出します
- うまく追加されないときは、「設定」の「音声入力の記録（不具合調査用）」を開き、「記録をコピー」で送ってください（アプリを閉じると消えます）

## 名称・日付・設計面積を畳む（v12.1）

名称・日付・設計面積の欄の右上「畳む ▲」で1行の要約（例「区画 A-12　2026/10/06・設計 16.000 m²」）に畳めます。畳んでいる間は、空いた分だけ図面が縦に大きくなります。要約をタップすると開きます。畳んだ状態は次に開いたときも保たれます。「新規」を押したときと、名称が未入力のまま保存しようとしたときは自動で開きます。

## 寸法の読み取り

- 三角形の最初の1つ: 「3.01、4.25、3」→ a・b・c
- 2つ目以降（c は接続辺で自動）: 「4.25、3.01」→ a・b
- 台形: 上底・下底・高さ（2つ目以降は上底・高さ）
- 「3点01」「三点〇一」「3メートル1センチ」「4m25」「ゼロ点85」なども数値に直します。読み取った値は入力欄の上に表示されます
- 数字だけを読み取ります。「はい」「OK」「オッケー」「よし」などの言葉は寸法としては読みません（「はい」「OK」は、数がそろった後なら追加の合図になります）
- 「もう一回」「1つ目」「三角」「十分」のように、言葉の一部になっている数字や回数・順番は寸法として読みません

Webアプリからキーボードの音声入力を自動開始することはできないため、最後のマイクのタップは手で行います。音声入力のオフライン可否は、スマホ本体のキーボード・言語パック・設定に依存します。個別の寸法欄にも「3点01」のような文字が入った場合は数値に直します。

## v11 で追加した機能

- **設計面積との比較**: 設計面積を入れると、合計の下に差（m²）と比率（%）を表示。保存・CSV・PDFにも出力
- **追加前のプレビュー**: 寸法を入れると、図面に追加位置を点線で表示し、その図形の面積と追加後の合計を表示
- **a と b の入れ替え**: b は接続辺の始点側、a は終点側に付きます。点線の図形で向きを確認し、逆なら「⇄ a と b を入れ替え」
- **途中の図形の修正**: 「追加した図形」の各行の「修正」から寸法を直せます。後ろにつながる図形も作り直し、成り立たなくなる場合は修正できません
- **細長い三角形の警告**: 最小角が20°未満の三角形は、テープの誤差が面積に大きく響くため警告
- **重なりの警告**: 既存の図形と重なる場合は警告し、追加前に確認（「接続方向を反転する」の付け忘れ対策）
- **頂点名**: 図面・接続辺の一覧・PDFに A, B, C… を表示
- **設定**（右上）: 面積の桁数（小数第1〜3位）・丸め方（四捨五入／切り捨て／切り上げ）・合計の出し方（合計してから丸める／図形ごとに丸めて合計）
- **屋外モード**（右上「☀ 屋外」）: 高コントラスト・大きいボタン
- **画面の消灯防止**: 使用中は画面を消灯させない（対応ブラウザのみ。設定で切り替え）

v10 以前に保存した図面もそのまま開けます（接続関係は点の位置から復元します）。

## GitHub Pagesで公開する

1. このフォルダー内のファイルをGitHubリポジトリのルートへ置きます。
2. GitHubの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、対象ブランチのルートを公開します。
4. 発行されたHTTPSのURLをスマートフォンで開き、ブラウザの「ホーム画面に追加」を選びます。

更新後、ホーム画面のアプリに反映されないときは、アプリを一度閉じて開き直してください。

## データについて

記録はブラウザの端末内ストレージに保存され、アプリ独自のサーバーには送信しません。音声入力の処理方法と通信の有無は、iPhoneまたはAndroidのキーボード設定に依存します。必要な図面は当日中にPDF・CSV・JSONで出力してください。

- **保存した面積は後から変わりません**（v12.5）: 保存した時点の丸め方（桁数・丸め方・合計の出し方）を記録ごとに保存し、保存履歴・CSV・PDF はその丸め方で出します。後で設定を変えても、保存済みの値は変わりません（変わるのは図面画面の表示と、次に保存する記録）。CSV には「面積の丸め」の列があります。v10 以前の記録は「小数第3位・四捨五入・合計してから丸め」で表示します
- **保存履歴で選んで合計**（v12.5）: 保存履歴の各図面のチェックを入れると、上のバーに選んだ件数と合計面積を表示します。選んだ図面すべてに設計面積があれば、設計面積の合計と差も表示します。「すべて選択」「選択を解除」も使えます
- **JSON から復元するときの検査**（v12.5）: 決まった形のデータだけを読み込みます。形式が正しくない記録は読み込まず、件数を表示します。端末内の保存データに読み込めない記録があったときは、上書きで消えないよう元のデータを `field-area-drawings-v2-rejected` に残します
- オフライン用のキャッシュは、このアプリのもの（`field-area-note-` で始まる名前）だけを入れ替えます。同じサイトの別のアプリのキャッシュには触りません

## 構成

- `index.html` — 画面
- `styles.css` — スマートフォン向けデザイン
- `mobile-input.css` — 下部ボタン配置
- `features.css` — v11・v12 の追加機能（プレビュー・設定・屋外モード・図面を見ながら入力）
- `numbers.js` — 音声入力の文字列から数値を取り出す
- `app.js` — 計算、図面、履歴、出力・復元
- `manifest.webmanifest` — PWA設定
- `service-worker.js` — オフラインキャッシュ
- `icons/icon.svg` — アプリアイコン

PWA機能はHTTPSまたはlocalhostで動作します。ファイルを直接開いた場合、計算と保存は使えますが、インストールとオフラインキャッシュは有効になりません。
